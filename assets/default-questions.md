# 默认精读结构

没有其他指定模板时使用。开头列论文标题、作者、发表/版本信息和一句核心结论；页码指实际阅读的原文 PDF。

1. 这篇论文需要解决什么问题？要验证什么科学假设？
2. 这篇论文中有哪些相关研究？如何分类？有哪些著名研究员？
3. 论文中提到的解决方案及其关键点是什么？
   - 论文如何设计实验？各个子实验得到的结论是什么？
   - 用于定量评估的数据集是什么？代码开源的话找到链接。
4. 论文贡献（三句话说明）新在什么地方？
5. 下一步还能基于它做什么？有什么工作可以深入？
6. 阅读过程中遇到的问题有哪些？

第五题是阅读者研究建议，第六题区分已解决的问题与仍需补证的细节。
